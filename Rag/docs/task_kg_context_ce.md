# Task-KG Context CE: 평가 완료 방법론

## 연구 문제

수주·제안 업무 문장에는 과업명, 수행 조건, 대상이 생략되거나 주변 문맥에만 나타날 수 있습니다. 질문과 원문 한 문장만 비교하면 관련성을 놓칠 수 있으므로, 후보 원문에 연결된 과업 KG 문맥을 재정렬 판단에 활용합니다.

## 지식 표현

| 노드 | 의미 |
|---|---|
| PCFProcess | 표준 업무 프로세스 |
| TaskFrame | 표준화한 과업 범주 |
| TaskMention | 문서에 등장하는 구체적 과업 표현 |
| Fact | 과업의 주장·조건 |
| EvidenceSpan | 주장을 뒷받침하는 원문 근거 |

근거 식별자를 유지하며 Fact 또는 TaskMention의 실제 원문 정렬 경로를 이용합니다. 위 노드가 항상 하나의 직선 사슬로 연결되는 것은 아닙니다.

## 검색 및 답변 절차

1. 질문만으로 검색 요구(Aspect)를 추출합니다. 정답·정답 근거는 추출 입력에 넣지 않습니다.
2. 전체 질문의 Dense 검색으로 원문 후보 40개를 확보합니다.
3. 각 후보와 연결된 TaskFrame, TaskMention, Fact를 조회합니다.
4. 짧거나 지시 표현이 있는 원문의 관련성 판단을 돕도록 과업 문맥을 보완합니다.
5. 원 질문과 문맥을 보완한 후보를 Cross-Encoder로 재정렬합니다.
6. 상위 5개 중심 원문을 공통 답변기에 전달합니다. 근거 본문 예산은 3,500토큰입니다.
7. 답변, 인용 및 해당 검증 결과를 저장합니다. 현재 표는 최초 답변을 주 평가 대상으로 사용합니다.

**후보 집합은 최초 Dense40 밖으로 확장하지 않습니다.** KG는 이 방법에서 후보 탐색 범위 확장보다는 재정렬 판단을 돕습니다. 이 점이 TH-KGR 및 PARS-RF와의 차이입니다.

## Aspect 해석

기존 450문항 기록에서 444문항은 원 질문을 단일 Aspect로 유지했고 복수 Aspect는 6문항이었습니다. 따라서 현재 성능을 다중 Aspect 분해의 효과로 단정하지 않습니다. 실험 결과가 직접 보여주는 것은 과업 문맥을 활용한 재정렬 조건의 성능입니다.

## 검증 결과의 범위

공통 답변기는 Qwen3.5-27B이며 현재 메인 테이블은 이전 Qwen3-8B 표와 구분합니다. Task-KG Context CE는 표에 포함된 방법 중 Recall@5, ROUGE-L, BERTScore에서 가장 높은 점수를 보였고 BLEU 최고값은 BM25입니다. 전체 450문항에는 개발 150문항과 이미 확인한 평가 300문항이 포함됩니다.
