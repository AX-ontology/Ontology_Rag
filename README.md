# Ontology_Rag

한국어 수주·영업·제안 업무 문서를 위한 과업 온톨로지 구축 및 근거 기반 질의응답 연구.

| 폴더 | 내용 |
|---|---|
| [Ontology/](Ontology/) | 온톨로지 구축 코드와 설정 |
| [Rag/](Rag/) | 과업 KG 검색 방법론, Aspect 기반 확장 설계, 실험 결과 |
| [data/](data/) | 『자주 이기는 제안서』 기반 QA 데이터셋과 원문·근거 연결 |

**자이제**는 김용기의 **『자주 이기는 제안서』**를 뜻하는 약칭입니다. 데이터셋은 이 책을 바탕으로 연구자가 구축했으며, 책 자체의 저작과 데이터셋 구축을 구분합니다.
